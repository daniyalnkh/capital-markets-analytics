Capital Markets Analytics

This project is a learning-focused toolkit for analyzing capital markets data. It includes pulling financial data from online sources, calculating returns and volatility, visualizing trends, and eventually building simple forecasting models.

The goal is to understand how assets like equities, cryptocurrencies, and foreign exchange behave over time — and to build a portfolio-ready analytics workflow step by step.

What This Project Will Do

As the project grows, it will include:

Data ingestion (pulling market data from sources like Yahoo Finance)

Cleaning and processing the data

Calculating daily returns, volatility, drawdowns, and correlations

Creating visualizations of asset behaviour

Building basic forecasting models (ARIMA, Prophet, etc.)

A Power BI dashboard for interactive exploration

This is a hands-on learning project to develop real finance + data analytics skills.
